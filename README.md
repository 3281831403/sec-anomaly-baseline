异常基线每周自动更新，攻击者慢慢抬高自己的访问量，基线跟着涨，最后再也不报警：基线由历史窗口计算，窗口大小以秒计且不包含当前点。偏离判定使用中位数与上分位等稳健统计，超过上分位乘以策略系数即视为异常。缓慢抬升由单次更新上限与冻结期共同抑制，更新频率与冻结长度均来自策略。每个实体维护自己的基线，批量判定时互不共享。不变量有两条：同一段历史重复计算得到相同基线；当前点不参与自己的基线。
